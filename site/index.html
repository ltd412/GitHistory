Everything you do with Git, in one window

Your history as a graph you can act on. Right-click anything for one consistent menu.

🌿

A graph you can read

Every branch in its own coloured lane, merges curving back into their parent, labels attached to their commits, stashes and work in progress in the graph.

🔀

Merge & rebase safely

Pick a merge strategy, get warned before a rebase rewrites pushed commits, abort with one click, undo a merge afterwards.

🧩

Three-way merge tool

Yours | Result | Theirs, apply or ignore each side, edit the result, and walk through every conflicted file in turn.

🔍

Side-by-side diffs

Whole-file diffs with word highlights and folded unchanged lines. Stage, unstage or discard files, hunks or single lines.

⏪

Undo almost anything

Commits, merges, rebases, resets, branch deletions and history edits can be undone and redone.

🗂️

Compare, blame, history

Compare any two revisions or the working tree, blame a file, browse its history, view or restore any version.

✏️

Edit history

Interactive rebase, plus quick reword, squash, fixup, move and drop right from the commit menu.

🌓

Made for daily use

Tabs for many repositories, quick launch, custom commands, compact mode, dark, light or by time of day.

Review and resolve with confidence

The two screens you spend the most time in when things get tricky.

Install

Download the file for your system from the latest release. Git must be installed.

SystemFileHow
macOS (Apple Silicon / Intel)…-mac-arm64.dmg / …-mac-x64.dmgOpen the .dmg, drag GitHistory to Applications. First launch: right-click → Open → Open.
Windows 10 / 11…-win-x64-setup.exe (or portable .zip)Run the installer. On the SmartScreen prompt: More info → Run anyway.
Ubuntu / Debian…-linux-amd64.debsudo apt install ./GitHistory-*-linux-amd64.deb
Any Linux…-linux-x86_64.AppImagechmod +x it and run it.
The builds are not code-signed yet, which is why macOS and Windows ask for confirmation the first time.

Also inside Paseo — on any device

The same graph, diffs and merge tool as a Paseo plugin: open several projects as tabs from Paseo's sidebar, on desktop, web or your phone.

paseo plugin install https://github.com/ltd412/GitHistory.git:plugins/paseo
The plugin runs git on the machine that runs the Paseo daemon and nothing else. Anyone who can sign in to that daemon can browse its folders and run git there — keep it behind a password on a trusted network.
